# Architecture Decisions (CR-VAS-008)

## Decision Record Template

Every material architecture should document an architecture decision
record.

```yaml

  id:
  value_stream:
  agentic_participation:
  pattern:
  rationale:
  authority:
  context:
  action_space:
  human_interaction:
  fallback:
  risks:
  measures:
  governance:
```

## Quality Attributes

AVS architectures should be evaluated against:

- value effectiveness
- semantic integrity
- authority integrity
- safety
- explainability
- observability
- resilience
- reversibility
- intervention
- scalability
- interoperability
- maintainability
- auditability

## Selection Criteria

The appropriate architecture pattern should be selected according
to:

- Value Stream structure
- decision materiality
- authority
- risk
- contextual complexity
- intervention requirements
- reversibility
- outcome criticality
- integration complexity

NOT according to:

- novelty
- agent count
- model size
- autonomy preference
