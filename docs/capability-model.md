# Capability Model (CR-VAS-006)

## Purpose

The capability model defines the six dimensions across which
organizational AVS maturity SHALL be assessed. Each dimension is
independent and contributes to the overall maturity profile. A single
arithmetic average SHALL NOT be the default maturity mechanism; the
profile SHALL remain visible with per-dimension levels and limiting
dimensions called out.

## Six Capability Dimensions

| ID | Name | Description |
|---|---|---|
| C1 | AVS Design & Semantic Modeling | Identify, model, and qualify AVS correctly. |
| C2 | Authority, Governance & Risk | Establish and govern delegated authority. |
| C3 | Operational Realization | Deploy and operate AVS reliably. |
| C4 | Value & Performance Management | Demonstrate agentic participation contribution. |
| C5 | Learning & Continuous Improvement | Improve AVS performance based on evidence. |
| C6 | Portfolio Scaling & Enterprise Integration | Scale AVS capability beyond isolated implementations. |

## C1: AVS Design & Semantic Modeling

Ability to identify, model, and qualify Agentic Value Streams
correctly.

Includes: Value Stream identification, agentic participation
modeling, agentic scope determination, intent modeling, authority
modeling, contextual interpretation, action-selection modeling,
boundary definition, semantic conformance.

## C2: Authority, Governance & Risk

Ability to establish and govern delegated authority.

This dimension is particularly important because delegated authority
is central to meaningful agentic participation.

Includes: authority scope, permissions, constraints, policies,
thresholds, escalation, revocation, auditability, risk controls,
regulatory controls, segregation of duties where applicable.

## C3: Operational Realization

Ability to deploy and operate AVS reliably.

Includes: runtime realization, agent/human coordination,
observability, exception management, intervention, escalation,
resilience, operational ownership, service management, incident
management.

## C4: Value & Performance Management

Ability to demonstrate that agentic participation contributes to
Value Stream outcomes. Directly builds upon CR-VAS-005.

Includes: outcome measurement, baseline comparison, incremental
value, time-to-outcome, quality, throughput, cost, intervention,
rework, risk-adjusted value, attribution confidence.

## C5: Learning & Continuous Improvement

Ability to improve AVS performance based on evidence.

Includes: performance analysis, exception analysis, intervention
analysis, boundary tuning, policy refinement, action-selection
improvement, adaptation analysis, controlled experimentation,
counterfactual evaluation, conformance revalidation.

## C6: Portfolio Scaling & Enterprise Integration

Ability to scale AVS capability beyond isolated implementations.

Includes: reusable patterns, shared capabilities, portfolio
governance, cross-Value-Stream coordination, enterprise architecture
integration, capability reuse, standards, common measurement,
investment prioritization, lifecycle management.

## Capability Progression Matrix

Per-dimension level expectations. The matrix is normative guidance;
an organization MAY deviate where evidence supports the deviation.

| Dimension | L1 | L2 | L3 | L4 | L5 |
|---|---|---|---|---|---|
| C1 Design | concepts recognized | standard defined | applied | optimized | enterprise reusable |
| C2 Authority | risks recognized | authority model defined | operational controls | continuously monitored | enterprise policy framework |
| C3 Operations | potential identified | operating model defined | production operation | performance managed | scaled operation |
| C4 Value | benefits hypothesized | metrics defined | metrics collected | value managed | enterprise value portfolio |
| C5 Improvement | ad hoc learning | improvement process defined | improvements executed | evidence driven | continuous adaptive improvement |
| C6 Scaling | isolated awareness | reference patterns | multiple implementations | portfolio management | enterprise capability |
