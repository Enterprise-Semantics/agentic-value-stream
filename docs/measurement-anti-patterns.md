# Measurement Anti-Patterns ; Agentic Value Stream

Per CR-VAS-005 §30 + AC-26, the repository explicitly identifies
anti-patterns. Each represents a way that measurement can become a
backdoor definition of agenticity.

## Anti-pattern 1 ; Agent Count As Value

Claim: "More agents = more value."

Verdict: False. The number of agents in a Value Stream is an
implementation choice, not a value metric.

## Anti-pattern 2 ; Autonomy As Performance

Claim: "More autonomy = better performance."

Verdict: False. Excessive autonomy can produce risk without
performance.

## Anti-pattern 3 ; Automation Rate As Agenticity

Claim: "More automated = more agentic."

Verdict: False. Automation and agenticity are different concepts.

## Anti-pattern 4 ; Decision Volume As Effectiveness

Claim: "More agent decisions = better AVS."

Verdict: False. Decision quality matters more than decision volume.

## Anti-pattern 5 ; Intervention Minimization

Claim: "Less human intervention = better AVS."

Verdict: False. An appropriate intervention rate may be desirable in
high-risk Value Streams.

## Anti-pattern 6 ; AI Model Quality As Value

Claim: "Model quality = Value Stream value."

Verdict: False. Model quality may matter, but it is not equivalent
to Value Stream value.

## Anti-pattern 7 ; Cost Reduction As Sole Value

Claim: "Cost reduction is the only value."

Verdict: False. Agentic Value Streams may create value through
quality, speed, resilience, customer experience, risk reduction,
innovation, capacity, revenue, and decision quality.
