# Value Realization ; Agentic Value Stream

Per CR-VAS-005 §6 + §7 + §20, value realization is the primary
measurement dimension. It evaluates whether agentic participation
improves the intended Value Stream outcome.

## Primary metrics

- Outcome Realization Rate. Successful intended outcomes divided by
  total intended outcomes.
- Outcome Improvement. AVS outcome minus baseline outcome. The
  baseline may be historical, non-agentic, human-only, automated,
  controlled experiment, or counterfactual simulation.
- Outcome Quality.
- Value Leakage. Value lost during realization.
- Value Recovery. Value recovered through agentic intervention.
- Exception Resolution Rate.
- Time-to-Outcome.
- Outcome Variance.
- Customer / stakeholder outcome.

## Risk-adjusted value

A high-value AVS may nevertheless be undesirable if it creates
disproportionate risk:

```
Risk-Adjusted Value = Realized Value - Expected Risk Cost
```

Different Value Streams may use financial risk, operational risk,
customer risk, regulatory risk, security risk, or reputational risk.
This SHOULD remain conceptual rather than prescribing a universal
financial formula.

## Counterfactual value

Where feasible, the repository SHOULD support comparison against a
baseline. Preferred baselines: human-only, automation-only, existing
operating model, historical, controlled experiment, simulation.
